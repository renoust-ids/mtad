MTad Features

MTad extends the original Tad with powerful data editing capabilities while retaining all the features you love.

Cell Editing

Double-click or right-click any cell to edit its value. Type-aware validation ensures data integrity for dates, numbers, booleans, and strings.

Pivot-Aware Editing

Edit pivot labels to rename values across all occurrences. Update aggregate cells with automatic group-by awareness.

Column Management

Right-click column headers to insert or rename columns. Reorder columns via drag-and-drop. Sort ascending or descending.

CSV Join & Materialization

Join multiple CSV files and materialize the result as a DuckDB table. Create virtual tables with automatic type detection.

Fast Pivot Analysis

Powered by DuckDB for lightning-fast analytics. Pivot, filter, aggregate, and sort millions of rows instantly.

Multi-Format Support

Open CSV, Parquet, SQLite, and DuckDB files. Export filtered results as CSV or Parquet.

Row & Column Insertion

Right-click any cell to insert a new empty row or a column header to insert a new empty column, with an auto-suggested unique name.

Grid Interaction Refinements

Hovering a cell draws a thick dark-blue border instead of a fill, keeping every value readable at all times.

Selection-Aware Context Menus

Right-clicking inside a multi-cell selection keeps the selection intact, so delete, duplicate, and copy actions apply to the whole group.

Built on Tad

MTad is a fork of Tad by Antony Courtney, extending it with data editing and manipulation features.

The original Tad provides the core pivot table UI, SlickGrid rendering, DuckDB integration, and the reltab SQL generation layer. MTad builds on this foundation to add:

  • Cell editing with double-click and right-click context menus
  • Pivot-aware editing for aggregate and leaf rows
  • Row and column insertion from the grid right-click menus
  • Column rename via header context menu
  • CSV join materialization into DuckDB tables
  • Selection-aware context menus that keep multi-cell selections on right-click

Release Notes

MTad 0.0.3 - August 2026

  • Insert Row - Right-click any cell and choose Insert Row to append a new empty row

  • Hover Highlight - Hovering a cell draws a thick dark-blue border instead of a fill, keeping cell values readable
