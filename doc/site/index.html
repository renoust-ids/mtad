MTad Features

MTad extends the original Tad with powerful data editing capabilities while retaining all the features you love.

Cell Editing

Double-click or right-click any cell to edit its value. Type-aware validation ensures data integrity for dates, numbers, booleans, and strings.

Pivot-Aware Editing

Edit pivot labels to rename values across all occurrences. Update aggregate cells with automatic group-by awareness.

Column Management

Right-click column headers to insert or rename columns. Reorder columns via drag-and-drop. Sort ascending or descending.

Join & Concatenate

Join your data against CSV, TSV, or Excel (.xlsx) worksheets and materialize the result as a DuckDB table (with per-sheet selection), or append external rows with automatic case-insensitive column matching and DuckDB type casting. Learn more

Fast Pivot Analysis

Powered by DuckDB for lightning-fast analytics. Pivot, filter, aggregate, and sort millions of rows instantly.

Multi-Format Support

Open CSV, TSV, Parquet, Excel (.xlsx), SQLite, and DuckDB files. Export filtered results as CSV or Parquet.

Row & Column Insertion

Right-click any cell to insert a new empty row or a column header to insert a new empty column, with an auto-suggested unique name.

Grid Interaction Refinements

Hovering a cell draws a thick dark-blue border instead of a fill, keeping every value readable at all times.

Selection-Aware Context Menus

Right-clicking inside a multi-cell selection keeps the selection intact, so delete, duplicate, and copy actions apply to the whole group.

Distribution Dialog

Right-click any column header and choose Distribution to explore a single column: binned histograms with an editable bin count, log scale, null bar and statistics panel for numeric columns, click-to-filter bar charts for categorical columns, and type-aware charts for date/time/timestamp columns. Drag (brush) across the bars to instantly filter the grid to a range.

Scatter Plot Matrix & Scatter Plot

Open Analytics ▸ Scatter Plot Matrix to explore pairwise relationships across numeric, temporal or categorical columns in an N×N matrix, color-coded by a categorical column, with Pearson correlation annotations. Click any off-diagonal cell — or use Analytics ▸ Scatter Plot — to open that pair as a full 2D scatter with a 2D brush (filter the grid on both axes), log X / log Y toggles, and a linear regression trend line and stats row.

Built on Tad

MTad is a fork of Tad by Antony Courtney, extending it with data editing and manipulation features.

The original Tad provides the core pivot table UI, SlickGrid rendering, DuckDB integration, and the reltab SQL generation layer. MTad builds on this foundation to add:

  • Cell editing with double-click and right-click context menus
  • Pivot-aware editing for aggregate and leaf rows
  • Row and column insertion from the grid right-click menus
  • Column rename via header context menu
  • Join & Concatenate — join CSV/TSV/Excel data with per-sheet selection and materialize into DuckDB tables, or concatenate external rows with automatic column matching and type casting
  • Selection-aware context menus that keep multi-cell selections on right-click

News

MTad 0.0.8 - September 2026

MTad adds a Confusion Matrix view under the Analytics menu — a co-occurrence (2D histogram) matrix between a chosen row variable and column variable, with adjustable binning, heat-mapped cells, conditional (row/column) normalization, and click-to-filter into the grid. The Scatter Plot Matrix now also reports eta (categorical×numeric) and Cramér's V (categorical×categorical) association stats, and a Help menu item offers a soft Check for Updates pointing to the latest release page.

MTad 0.0.7 - September 2026

MTad adds Excel (.xlsx) import with native DuckDB type inference — a worksheet picker when opening (or joining against) a multi-sheet workbook, and an automatic per-column inference fallback for mixed-type columns (numeric, TIME, TIMESTAMP, DATE or VARCHAR, exactly like CSV). The Join dialog now accepts Excel sheets alongside CSV/TSV files and materializes the result as a new editable DuckDB table.

MTad 0.0.6 - September 2026

MTad adds a Scatter Plot Matrix (SPLOM) and a standalone Scatter Plot view under the Analytics menu — pairwise scatters with Pearson correlation, optional categorical coloring, sampling, 2D brush-to-filter, log scales and linear regression — and strictly separates Table Filters and Analytics Filters into their own editors (table filters are set only manually; analytics filters also come from View interactions).

MTad 0.0.5 - September 2026

The Distribution dialog now charts temporal (date/time/timestamp) columns with type-aware labels, adds double-click-editable bin counts and a categorical min-frequency threshold, and splits the footer into Table Filters and Analytics Filters with live SQL summaries, apply toggles, and one-click clear buttons.

MTad 0.0.4 - September 2026

MTad adds interactive column histograms: right-click any column header to open a histogram of that column with a bin-count slider, log scale, null bar, statistics panel, and brush-to-filter into the grid.

MTad 0.0.3 - August 2026

MTad adds row and column insertion, hover highlighting, and selection-aware context menus to the Tad foundation.

Build from source to try MTad. See the GitHub repository for instructions.

Release Notes

MTad 0.0.8 - September 2026

New Features
  • Confusion Matrix - Analytics ▸ Confusion Matrix renders a co-occurrence (2D histogram) matrix between a chosen row variable and column variable. Numeric/temporal columns auto-bin (adjustable row/col bin counts), categorical columns use their values; cells are heat-mapped by value and support conditional (row/column) normalization, a minimum-occurrence threshold, and click-to-filter into the grid
  • SPLOM association stats - the Scatter Plot Matrix reports eta (categorical×numeric) and Cramér's V (categorical×categorical) association statistics
  • Soft check-for-updates - a Help ▸ Check for Updates item points to the latest release page

MTad 0.0.7 - September 2026

New Features
  • Excel (.xlsx) import - open Excel workbooks as data sources, imported through DuckDB with native type inference (numeric, TIMESTAMP, DATE, TIME, string)
  • Worksheet picker - when a workbook has several sheets, a picker dialog (and a Join sheet dropdown) chooses which worksheet to open/join, routing each sheet to its own table
  • Mixed-type column fallback - if a column mixes types, per-column inference (INTEGER, DOUBLE, TIME, TIMESTAMP, DATE, else VARCHAR, empty → NULL) imports the sheet end-to-end
  • Excel joins - the Join dialog now accepts .xlsx sheets alongside CSV/TSV files and materializes the fused result as an editable DuckDB table

MTad 0.0.6 - September 2026

New Features
  • Scatter Plot Matrix - Analytics ▸ Scatter Plot Matrix shows pairwise scatters across up to 10 numeric, temporal or categorical columns, with Pearson correlation annotations, categorical coloring, sampling, and a searchable multi-select
  • Scatter Plot - Analytics ▸ Scatter Plot (or clicking an off-diagonal SPLOM cell) opens any single X/Y pair as a 2D scatter with 2D brush-to-filter, log X/Y toggles, linear regression trend line and stats row
  • Strict Table / Analytics filter separation - the footer uses two independent editors (table-filter-editor and analytics-filter-editor); table filters are set only manually, while analytics filters also come from View interactions (brushing, bar clicks)
  • Categorical-only SPLOM - the matrix can now be built from categorical-only column selections

MTad 0.0.5 - September 2026

New Features
  • Temporal Distribution charts - the Distribution dialog charts date/time/timestamp columns with type-aware labels (YYYY-MM-DD, HH:MM, YYYY-MM-DD HH:MM)
  • Editable bin counts - double-click the bin-count value to type a number directly; categorical charts get a min-frequency threshold to hide rare values
  • Table & Analytics Filters split - the footer separates the two filters into their own editors with live SQL summaries, apply toggles, and one-click clear buttons
